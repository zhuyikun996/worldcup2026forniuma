# 英国十日 · 行程手账

2026 年夏末英国十日行程（曼彻斯特 → 利物浦 → 牛津 → 伦敦）的网页手账，基于 Next.js（App Router）构建。

## 运行

```bash
npm install
npm run dev    # 开发模式 http://localhost:3000
npm run build  # 生产构建
npm start      # 生产运行
```

## 说明

- `app/` — Next.js 应用（页面、全局样式）
- `public/offline.html` — 单文件离线版，无需 Node，双击即可在浏览器打开
- 数据来源：飞书文档《Travel Plan》
